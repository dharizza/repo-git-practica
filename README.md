# Directorio de unidades (repo de práctica)

Repo de práctica para la sesión de Git en equipo. El contenido es **ficticio**:
sirve para practicar ramas, pull requests, conflictos y lanzamientos sin riesgo.

## Archivos

- `unidades.md`: unidades, edificio y teléfono.
- `horarios.md`: horarios de atención.
- `avisos.md`: avisos vigentes.
- `CHANGELOG.md`: cambios por versión.
- `VERSION`: versión actual.
- `participantes/`: un archivo por participante (Ejercicio 1).

## Reglas del repo

- Nadie hace commit directo a `main`: todo entra por pull request con 1 aprobación.
- Una rama por cambio: `feature/...`, `fix/...`, `docs/...`.
- Los lanzamientos son tags anotados `vMAYOR.MENOR.PARCHE`.
- Las ramas ya mezcladas se deben eliminar.
